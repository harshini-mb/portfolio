## Featured project

**StructureX** is an ML pipeline that takes building and infrastructure parameters and returns an early structural risk indication through a Streamlit dashboard.

Stack: Python, Pandas, Scikit-learn, Random Forest, Streamlit. [View it live](https://structurex-five.vercel.app/).

## Built with

- HTML and CSS in a single `index.html`, with a small amount of vanilla JavaScript (copy-to-clipboard for the email button)
- [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque) and [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) from Google Fonts
- No frameworks and no build step

## Features

- Responsive layout for mobile, tablet and desktop
- Light and dark themes that follow the device setting
- Hover and tap effects on cards, timeline entries and buttons
- Respects the reduced-motion setting
- Photos embedded in the file, so the site is fully self-contained
